ESP32APRS_CDU (LU6JMF) — Installer v2.1.3-lu6jmf

Custom firmware for the LU6JMF-10 digipeater, based on ESP32APRS_Audio (nakhonthai). Flashes firmware + icons in a single click, directly from your browser (Chrome or Edge), no software installation needed.

  1. Connect the ESP32 to your computer via USB cable.
  2. Click the button below and select the device's serial port.
  3. Wait for flashing to finish (~1 minute).
Your browser doesn't support Web Serial. Use Google Chrome or Microsoft Edge on a computer (doesn't work on mobile). This page needs to be served over HTTPS to work (it already is).
Warning: this erases everything currently on the device (including WiFi/APRS configuration) and flashes from scratch. After installing, configure WiFi, callsign, and other settings through the device's own web interface (it creates its own WiFi network on first boot).

Already have a device running (this firmware or another one) and want to update it without USB? See the release notes ("Existing device" section) for the no-USB update steps.
