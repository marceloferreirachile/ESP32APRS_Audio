ESP32APRS_CDU (LU6JMF) — Instalador v1.9-lu6jmf

Firmware customizado do digipeater LU6JMF-10, baseado no ESP32APRS_Audio (nakhonthai). Grava firmware + ícones em um único clique, direto pelo navegador (Chrome ou Edge), sem instalar nada no computador.

  1. Conecte o ESP32 no computador via cabo USB.
  2. Clique no botão abaixo e selecione a porta serial do dispositivo.
  3. Aguarde a gravação terminar (~1 minuto).
Seu navegador não suporta Web Serial. Use Google Chrome ou Microsoft Edge no computador (não funciona em celular). Esta página precisa estar em HTTPS para funcionar (já está).
Atenção: isso apaga tudo que já estava gravado no dispositivo (configuração de WiFi/APRS incluída) e grava do zero. Depois de instalar, configure WiFi, indicativo e demais ajustes pela própria interface web do dispositivo (ele cria uma rede WiFi própria no primeiro boot).
